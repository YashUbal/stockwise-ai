# StockWise AI

An explainable inventory optimization platform designed for SMEs.

## Problem
Small businesses often rely on Excel sheets and intuition to make inventory decisions, leading to overstocking or stockouts.

## Solution
StockWise AI helps businesses forecast demand and generate inventory recommendations using machine learning.

## Planned Features
- CSV/Excel upload
- Demand forecasting
- Inventory recommendations
- Explainable AI insights
- Scenario simulation

## Tech Stack
- Python
- FastAPI
- XGBoost
- React
- Tailwind CSS
- Scikit-learn
